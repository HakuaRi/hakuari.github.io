五年

发表于2025-12-22|更新于2025-12-22|网站相关
|浏览量:

时间走走停停，停停走走。五年，60个月。

如果是站在 2021 年那个燥热的准初三的暑假，这一连串数字对我来说只是物理试卷上需要换算的t。但当我此刻坐在 2025 年的大学宿舍，重新打开那个积灰的 source 文件夹时，这五年不再是线性的时间轴，而是一块被压缩的数字沉积岩。

每一行代码都是时间的化石，每一个废弃的文件夹都是地质运动留下的断层。

今天，我试图用一把名叫“回忆”的地质锤，敲开我这五年的岩层。

渊源

一切的起点并不光彩，甚至带着某种模仿者的笨拙。

那时候，我对 Web 的理解还停留在“在浏览器里画画”。我流连于“模板之家”这类早已过时的素材网站，试图找一个现成的壳子来安放我无处宣泄的表达欲。那时的我天真地以为，只要把 index.html 下载到本地，我就拥有了一个网站。

直到我误打误撞地推开了 GitHub 的大门。那是一段混杂着挫败与亢奋的日子。CSDN 上那些语焉不详甚至互相矛盾的教程，是我唯一的炼金术残卷。我像个对着咒语书瞎念的学徒，不知道哪一句代码会让屏幕亮起，也不知道哪一句会让它彻底崩溃。

当 Virtual_NeutroN.github.io 第一次在浏览器地址栏里跑通的那一刻，物理世界的孤岛被打破了。那不仅是一个网页，那是我的神经突触第一次接入了广袤的数字洋流，流淌着 2020 年那个夏天的血液。

坎坷

翻开 archived 中的第一篇博文，那个稚嫩的自己正隔着屏幕对我喊话。

那时的我写道：“为什么选择 Hexo？简单，简单，还是简单。”

如今读来，这句为了“简单”而做出的选择，充满了宿命般的讽刺。为了这个“简单”，我随后花费了五年时间去折腾最复杂的配置。在博文的最后，我记录了那个差点劝退我的瞬间——“当我修改好模板的 config.yml 时，一种激动的心情促使我立马 Hexo s……可是，致命 bug，无法运行。”

那是我与开源世界的第一次正面碰撞。直到终于在 GitHub 的迷宫里顺藤摸瓜，找到了 Butterfly的那一刻，我并未意识到，这个偶然的决定，将定义未来五年的视觉基调。

新生

地质层来到 v2.0 至 v4.0 时期，这是 Organxy 生态最野蛮生长的年代。

对着更新日志看去，全是那个年纪特有的贪婪与躁动。

v2.2.0：元素周期表上线，那是我试图数字化物质世界的第一次尝试。

在那段日子里，我怀揣着一个巨大的野心——为了纪念元素周期表诞生 150 周年，我想构建一座线上的化学圣殿。我试图把一百多种实物元素的照片全部数字化，塞进那个简陋的网页里。

这是一个典型的“初生牛犊”式的错误。现实的带宽和存储成本迅速击碎了这个堂吉诃德式的梦想。那个项目“难产”了，只留下了一个纯 HTML 手写的周期表骨架。

但我没想到的是，这个在当时看来是个失败品的“骨架”，却拥有着惊人的生命力。它那通过笨拙的 < table > 和 < div > 堆砌起来的结构逻辑，竟然像基因一样遗传了下来。

爆发

v3.0.0：小工具、音乐、友情链接、甚至那个带有密钥系统的“营销号生成器”。

v3.1.0：增加了“斗一往事”。

那是一个在物理围墙内寻找裂缝的时期。学校机房成了我的地下电台，我把对枯燥生活的反抗写进了代码里。我们在这里记录班级的随机学号，记录“地球Online斗一副本”的更新日志。增加的每一个功能，都是为了在严密的电教监管下，凿出一扇通往自由的窗。

那时候的博客，像一个杂乱无章的百宝箱，塞满了我的黑话、我的同学、我无处安放的表达欲。虽然它是混乱的（v4.0 之前甚至充满了“垃圾文章”），但它是鲜活的。

舍离

v5.0.0 (2023.1.24)，这是 Organxy 历史上的分水岭。

日志里冰冷地记录着：“永久删除数电专栏”、“删去冗杂文章”、“归类大部分过去的文章”。

这是一场痛苦的大灭绝。进入高二下学期疫情阳了在家，我开始审视这个过于臃肿的百宝箱。我意识到，过度的杂乱正在掩盖核心的价值。于是，我举起了奥卡姆剃刀。

“重启万物”不再是一个简单的脑洞，它开始被系统化；Organxy Lab 的入口被正式开设。我开始从一个单纯的“记录者”向“架构师”转型。原本那个名为 Virtual_NeutroN 的少年，开始觉得旧的壳体过于狭窄。他删除了那些不再成熟的文字，试图建立一个新的秩序。

道别

v6.0.0 (2024.9.2) 的日志只有寥寥数语：“这一年半都去建设 Organxy Lab 去了，导致这边摆了。”

这句自嘲背后，是我脑洞的彻底分裂。主域名停留在了 2023 年，像一座无人维护的灯塔，任由海浪拍打。而真正的文明重心，已经迁移到了 Lab 的新大陆。

《重启万物》的世界观终于脱离了博客的载体，成为了独立的 Organxy Wiki。那个曾经在 v3.0 时代为了“简单”而存在的博客，似乎完成了它的历史使命。

在这一年的九月，还发生了一个不起眼却昂贵的插曲。

陪伴了我三年的旧域名 virtual-neutron.top 正式结束了它的使命。取而代之的，是更简洁、定位更强的 organxy.com。

新域名的价格翻了不止一倍。对于一个流量枯竭、几乎没有盈利的个人静态站来说，这完全是一笔不理性的消费。但我发现，每当收到续费通知时，我依然会机械式地按下支付键。

这不再仅仅是为了维持一个网址的连通性，而更像是一种近乎偏执的仪式。只要这个更名后的 organxy.com 还能被全球的 DNS 解析，那个从初中开始构建的世界就依然拥有合法的领土。这笔“房租”，买的不是流量，是我的数字生命延续权。

尾声

现在的编程太容易了。我只需要对 AI 说一句话，它就能吐出比我五年前熬夜一周写出来的还要漂亮的代码。

既然如此，我为什么还要费力维护这个只有静态页面的“古董”博客？为什么还要费尽周折去建立一个存放旧代码的“博物馆”？

因为 AI 可以生成完美的像素，却无法生成“时间”。

它无法生成 2020 年初次遇到 config.yml 报错时的绝望，无法生成 2022 年在高中机房里把网易云 API 伪装成学习资料时的窃喜，也无法生成 v5.0 删库时的那种决绝。

这五年的更新日志，是我在这个网络中存在过的唯一证明。从 v2.0 的懵懂，到 v4.0 的狂热，再到 v6.0 的沉淀。

它简陋，它不完美，但它是我亲手堆砌的。

这就足够了。

记忆里总有一个声音，在周末的午后穿过房门刺入耳膜：“整天搞这些不务正业的东西有什么用？”

其实，我心里比谁都清楚，我不是搞计算机的那块料。我没有天才般的逻辑，写不出改变世界的算法，甚至连这个博客的 CSS 都是东拼西凑的“缝合怪”。

但我依然像个蹩脚的推销员，一次次向周围的人展示那些我眼中的“辉煌杰作”。看，这是我写的元素周期表！看，这是我做的班级日志！而在他们客套的点头和茫然的眼神中，我渐渐意识到，这些所谓的“杰作”，在现实的引力面前，不过是一场自我感动的黄粱一梦。

梦醒了，代码能当饭吃吗？不能。这些静态页面能换来绩点吗？不能。

可我为什么还是舍不得关掉它？

因为在那些被斥责“不务正业”的周末，在那些与报错代码死磕的深夜，我感受到了某种比现实更真实的东西。

我们构建这些虚幻的数字楼阁，不是为了证明我们是天才，而是为了证明我们没有被平庸的生活彻底吞噬。哪怕由于天赋所限，这些代码永远只能是业余的玩具；哪怕这一切终将像黄粱一梦般随风消散。

但至少，在那个梦里，我曾是造物主。我推着那块名为“Organxy”的巨石，一次次推上山顶，哪怕它注定滚落，那推动巨石时手掌上磨出的茧，是真的。

在终端按下 Ctrl + C 终止本地服务器的那一刻，屏幕上总会跳出一行小字：“Goodbye”、“Farewell” 或是 “Have a nice day”。

以前，这只是一行冷冰冰的系统提示，标志着 localhost 连接的断开。

但现在，在这个逐渐沉寂的博客里，再看到这些字眼，竟生出一种莫名的悲壮与心酸。

仿佛我刚刚在一个私有的端口里，独自维系了一个繁华的宇宙。而随着这组快捷键的按下，那个世界瞬间坍缩、熄灭，只留下光标在黑色的虚空中孤独闪烁。

每一次“再见”，都像是在为一个无人知晓的时代，进行一次小型的谢幕。

或许，我应该在这里写下
